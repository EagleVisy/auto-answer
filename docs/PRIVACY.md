# 隐私与安全说明

## 程序的数据流

本地截图 → 本地 OCR 和范围确认 → 你启用后将裁剪图发送给 DeepSeek 官方 API → 本地显示结果。

可选网页搜索会把由 OCR 提炼的查询词发送给搜索服务，并读取少量公开网页。不要在含个人信息或保密材料的题目上启用搜索。

## 本地保存

程序在当前用户的本地应用数据目录保存设置、DPAPI 加密密钥、答题历史与历史截图。历史可在程序界面删除；删除操作不代表能够删除服务商已经收到的数据。

API Key 仅在软件界面配置。不要放进 `.env`、源码、测试、命令历史或 GitHub Issue。不要提交本机运行数据目录。

## 公开仓库的材料边界

公开副本采用源码白名单整理，不包含私人截图及其 OCR 文件、真实 API Key、加密凭据、答题数据库、内部评测数据、本机诊断日志、个人路径或完整开发环境。测试使用合成文本和画布；假密钥只用于 Mock。

`.gitignore` 是预防规则，不是内容审计。提交前仍应检查 `git diff --cached` 和实际文件列表。已经提交过的敏感数据不能靠后来加入忽略规则清除。

## 限制

程序不能保证截图中没有你无意框入的个人信息。请在采集前检查窗口范围。代码规范检查仅用于展示格式，生成代码不会自动执行，也不能因此认为生成代码可以不经审查地运行。

发现问题时，请先停止识题，并通过不含截图、密钥或身份信息的描述联系仓库维护者；不要把秘密直接公开在 Issue 中。
