开发过程中用户提供的真实截图及 OCR 提取文本未上传。直接依赖这些材料的用例未复制；保留的题目、选项与文件名均为合成或泛化测试数据。公开测试不应要求你补入任何私人附件。

## 交互与运行边界

- 项目为 Windows 桌面应用，部分测试需要 Windows、Qt 桌面会话和本地 OCR 依赖。
- 网络响应以 Mock 为主，另有只在127.0.0.1动态端口运行的socket/TLS/SSE取消测试；不向真实 AI API 发送问题，不读取真实密钥。
- 部分桌面测试会采集临时区域，不上传，但运行时仍应避开私人窗口。
- 真实跨应用空格需要显式开启 `AUTO_ANSWER_INTERACTIVE_KEY_TEST=1`，默认跳过。开启后可能改变当前焦点和发送空格，请在隔离桌面操作。
- 原生钩子安装/卸载、合成按键边沿测试不等价于真实物理按键验收。最小化跨应用空格仍列为待验证。
- 自动回归不执行生成的实操代码；不会读取题目涉及的 Excel/CSV 文件。
