# Auto Answer

用于 Windows 的桌面练习助手：在本机识别题目范围，经你确认启用后，将裁剪截图发送给 DeepSeek 官方 API，并把答案显示在独立置顶窗口。

> **本项目由 gpt-6.1 sol 完成。** 项目需求、交互反馈与发布由项目维护者提供和确认；代码实现、调试与文档主要由 gpt-6.1 sol 在 DeepSeek Harness 中完成。此说明仅用于开发来源署名，不表示相关模型或服务提供商对项目作出官方认可。

仅用于自学及明确允许 AI 辅助的练习。不提供监考绕过、录屏规避、自动选择选项或自动提交功能。答案和代码都需要你自行核对。

## 功能

- 本地 OCR 自动查找题干和选项，也支持手动框选。
- 画面稳定后再请求，题目改变、暂停或修改设置会取消旧任务，拒绝迟到答案。
- 独立置顶答案层，支持字体、字号、颜色和背景透明度；设置窗口最小化后仍可显示答案。
- 实操题显示简单但必要的 Python 代码，不加注释或解释；代码仅展示，不会自动执行或读取题目数据文件。
- 本地保存题目截图和最终答案，可搜索、逐条删除或清空。
- 可选网页搜索辅助；密钥通过 Windows DPAPI 保护。
- 空格锁定输出时，后台定位继续，但 AI 请求暂停；工作台也有锁定按钮。

## 从源码运行

需要 Windows 10/11、64 位 Python。开发时使用 Python 3.13；其他版本请自行验证兼容性。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

首次启动默认暂停，不会自动上传。请在软件的“AI 连接”页填写你自己的 DeepSeek 官方 API Key，不要把密钥写进源码、截图、Issue 或提交记录。确认截图上传和 API 费用提示后，再开始识题。

依赖包含 OCR 模型和桌面运行库，首次安装可能较慢。程序不会为你创建题目所需的 Excel/CSV 数据文件。

## 使用

1. 在“AI 连接”中配置密钥，选择是否启用网页搜索。
2. 在工作台选择自动查找，或手动框选完整题目。
3. 调整答案窗口位置，开始识题。
4. 答案显示后自行核对；实操代码需在你自己的 Python 环境、原始数据文件和依赖齐备时运行。
5. 停止识题后不再采集或上传，退出程序会释放后台监听。

## 隐私与上传边界

识题和定位在本机进行，但 AI 作答需要把题目截图发送给 DeepSeek。请勿框入聊天、身份信息、账号凭据或其他无关窗口。API 费用和服务端数据处理以服务商条款为准。

答题历史和截图默认保存在本机用户数据目录，API Key 使用当前 Windows 用户的 DPAPI 加密。这不等同于“截图不会离开电脑”，也不能替代设备本身的安全保护。

**本公开仓库不包含开发者的私人截图、OCR 提取文本、API Key、DPAPI 文件、答题历史、内部评测材料或本机配置。** 公开测试使用程序合成的数据、HTTP Mock 和回环网络取消测试，不依赖私人附件或真实 AI 凭据。详见 [隐私说明](docs/PRIVACY.md)。

## 测试

```powershell

```

测试会打开部分桌面窗口、执行本地 OCR 或采集临时屏幕区域，但不向真实 AI API 发送请求。请勿在含敏感内容的桌面上运行桌面自检。真实跨应用空格验收属于显式交互测试，默认跳过；不能把跳过当成通过。

用户提供的原始问题截图及其 OCR 回归材料未公开，对应私有用例也没有复制到此仓库。公开测试的覆盖范围见 [测试说明](docs/TESTING.md)。

## 已知限制

- OCR 可能漏字母、误分栏或识别不了复杂公式和图形；框入全部内容不代表答案一定正确。
- 缺原始数据时只给待运行代码，不声称已经得到真实数值或正确选项；必要参数不足时可能不给代码。
- 混合 DPI 多屏、独占输入程序和 UAC 安全桌面没有完整覆盖。
- **最小化后跨应用空格锁定仍缺正常桌面实键验收。** 原生监听安装/卸载及状态逻辑有测试，但不能据此保证任意应用中的按键投递；可先使用工作台锁定按钮。
- 此项目不适用于禁止 AI 辅助的考试，也不保证模型正确率或固定响应时长。
